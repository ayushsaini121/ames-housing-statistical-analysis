# Statistical Modeling and Analysis of the Ames Housing Dataset

This project presents a comprehensive statistical analysis of the Ames Housing dataset
with a focus on understanding the factors influencing residential property prices.

The emphasis of this project is on **statistical rigor, interpretability, and model
diagnostics**, rather than black-box prediction.

---

## Dataset
- Source: Ames Housing dataset (`modeldata` package in R)
- Observations: 2,900+
- Features: 80+ numerical and categorical variables

---

## Objectives
- Perform exploratory data analysis (EDA)
- Fit and evaluate probability distributions
- Conduct hypothesis testing with assumption validation
- Build and interpret multiple linear regression models
- Evaluate out-of-sample predictive performance
- Emphasize uncertainty, assumptions, and model limitations

---

## Methods Used
- Descriptive statistics and visualization
- Probability distribution fitting
- Hypothesis testing:
  - Two-sample t-tests
  - One-way ANOVA
  - Chi-square tests
- Multiple linear regression
- Residual diagnostics and RMSE evaluation
- Reproducible statistical workflows

---

## Technologies
- R
- Libraries: tidyverse, modeldata, fitdistrplus, ggplot2

---

## Key Takeaway
Statistical models are most useful when their assumptions, limitations,
and uncertainty are carefully examined. This project demonstrates how
classical statistical methods remain highly effective for structured,
real-world data analysis.

---

## How to Run
1. Install required packages using `requirements.R`
2. Run `analysis.R` to reproduce the full analysis
